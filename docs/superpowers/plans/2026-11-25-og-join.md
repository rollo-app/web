# Imagen dinámica para `/join/<CÓDIGO>` — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que `/join/<CÓDIGO>` sirva `og:*` por código y una imagen 1200×630 con la tarjeta del rollo.

**Architecture:** `vercel.json` reescribe `/join/:code` a la función `api/join.ts`. La función toma el `join/index.html`
del build y reemplaza el bloque `<!--og-->…<!--/og-->` con los datos de la vista previa pública
(`GET https://api.rolloproject.com/events/<CÓDIGO>?any=1`). `api/og/join/[code].ts` dibuja el PNG con **satori +
@resvg/resvg-js**. Toda la lógica vive en `api/_lib/` (el `_` hace que Vercel no la publique como función) y los handlers
son finos.

**Tech Stack:** Vercel Node functions (handler Web `GET(request: Request): Response`), TypeScript, satori 0.63, @resvg/resvg-js 2.6, @fontsource/inter 5.3 (`.woff`), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-25-og-join-design.md`

**Cambio respecto del spec:** `@vercel/og` 1.0.3 no arranca en Node ESM (`Dynamic require of "fs"` en harfbuzzjs).
Usamos satori + resvg directo: es lo mismo que trae por dentro, y resvg ya estaba en el repo.

## Global Constraints

- Código de unirse: `^[A-Za-z0-9]{6}$`, normalizado a mayúsculas.
- API: `https://api.rolloproject.com`, `/events/<CÓDIGO>?any=1`, timeout 1500 ms.
- Portada válida: `^\/covers\/[A-Za-z0-9._\/-]+$` y sin `..` (igual que la página).
- Imagen 1200×630. Degradé sin portada: `#3155F5` → `#0b1a5c` a 135°. Cobalto de la marca: `#3155F5`.
- Textos: "Te invitaron a", "N personas", "Te invitaron a este rollo en Rollo." / "Te invitaron a este evento en Rollo.",
  `<title>` "<nombre> · Rollo Project".
- Caché del HTML: `public, max-age=0, s-maxage=300, stale-while-revalidate=86400`. Imagen OK:
  `public, max-age=31536000, immutable`. Fallback (302 a `/og.png` o imagen sin portada por error de red):
  `public, max-age=60, s-maxage=60`.
- Código y comentarios en inglés; textos del sitio, commits y PR en español.

## Review Focus

1. **Nombre con `"`, `<`, `&` o emoji:** el HTML queda escapado y válido, y la imagen se dibuja igual (un emoji puede
   quedar en blanco, sin romper). Tests en Task 2 y Task 3.
2. **Nombre muy largo (120 caracteres):** máximo 2 líneas con "…", sin pisar la marca. Test en Task 3 (renderiza sin
   error) y control visual en Task 5.
3. **Backend colgado:** la página sale igual, con las etiquetas genéricas, en ~1,5 s. Test en Task 2 con un fetch que
   nunca resuelve.
4. **Código en minúscula o con barra final (`/join/abc123/`):** las etiquetas usan `ABC123`. Test en Task 2.
5. **Rollo de un solo día y rollo que cruza de año en la zona del rollo:** la fecha se lee bien. Tests en Task 1.

### Task 1: Datos de la vista previa (pedido, validación, fecha, versión)

**Files:**
- Create: `api/_lib/preview.ts`
- Test: `scripts/__tests__/og-preview.test.ts`

**Interfaces:**
- Produces:
  - `type Preview = { type: "trip" | "event"; name: string; coverUrl: string | null; description: string | null; startsAt: number; endsAt: number; timezone: string; revealed: boolean; memberCount: number | null }`
  - `API_URL = "https://api.rolloproject.com"`
  - `normalizeCode(raw: string | null | undefined): string | null`
  - `fetchPreview(code: string, opts?: { fetch?: typeof fetch; timeoutMs?: number }): Promise<Preview | null>`: null
    ante 404, 429, error, timeout o un JSON sin `name` string.
  - `safeCoverPath(coverUrl: unknown): string | null`
  - `formatDates(startsAt: number, endsAt: number, timeZone: string): string`
  - `caption(p: Preview): string`: fecha + (`!revealed && memberCount` número ? " · N personas" : "").
  - `previewVersion(p: Preview): string`: sha256 de nombre|portada|inicio|fin|zona|count|revealed, 10 hex.

    `{}` → null; fetch que nunca resuelve con `timeoutMs: 20` → null en menos de 200 ms. La URL pedida es
    `https://api.rolloproject.com/events/ABC123?any=1`.

### Task 3: La imagen

**Files:**
- Create: `api/_lib/og-card.ts`, `api/og/join/[code].ts`
- Modify: `package.json`: `@resvg/resvg-js` pasa a `dependencies`, junto a `satori` y `@fontsource/inter`.
- Modify: `vercel.json`: `"api/og/join/[code].ts": { "includeFiles": "node_modules/@fontsource/inter/files/inter-latin-{400,700}-normal.woff" }`
  si el trazado automático no los encuentra (se confirma en Task 5).
- Test: `scripts/__tests__/og-card.test.ts`

**Interfaces:**
- Consumes: Task 1 (`Preview`, `caption`, `safeCoverPath`, `fetchPreview`, `API_URL`, `normalizeCode`).
- Produces:
  - `cardTree(p: Preview, cover: string | null): object`: el árbol de satori; `cover` es un data URI.
  - `renderCard(p: Preview, cover: string | null): Promise<Uint8Array>`: PNG.
  - `fetchCover(path: string, opts?: { fetch?; timeoutMs? }): Promise<string | null>`: data URI, o null si falla o no
    es `image/*`.
  - `handleOg(request: Request, deps?): Promise<Response>`; el código sale del último segmento del path.
- Layout (de la opción A del spec):
  - márgenes de 72 px;
  - marca arriba a la izquierda: círculos del logo de 40 px + "Rollo Project" 28 px bold, blanco;
  - abajo a la izquierda: "Te invitaron a" 30 px al 85 %, el nombre 68 px bold (`lineClamp: 2`) y el caption 30 px
    al 85 %, con un ancho máximo de 860 px;
  - velo: `linear-gradient(90deg, rgba(0,0,0,.72), rgba(0,0,0,.35) 55%, rgba(0,0,0,0) 80%)` más uno de abajo hacia
    arriba al 40 %;
  - sin portada: el degradé de las constantes y los círculos en blanco.

- [ ] **Step 1: Write the failing tests**
  - `renderCard` con y sin portada (un JPEG chico como data URI): PNG con firma `\x89PNG` y 1200×630 (bytes 16–23

  - `handleOg`:
    - vista previa OK → 200, `image/png` y caché larga;
    - vista previa null → 302 a `/og.png` con caché corta;
    - código inválido → 302 sin llamar al fetch;
